A rail with no building linked reads "Nothing connected"
A rail on a drone lane's track lists only that track's machines; the lane's other tracks no longer mix in

A machine card shows each ingredient and the product per minute as now / full speed, and a starved machine adds a red "short N" line for each ingredient it lacks (its whole per-minute need, since the game does not expose what is arriving). Figures no longer overlap at any ingredient count

Storage and stations on a rail's network pass items along and never count as makers
A machine card shows over each ingredient how many it needs per minute at full speed, and under an ingredient the machine is short of, a red "short N/min" and a red outline. N is the need minus what has arrived in the input store over the last minute (measured while you look at the machine, so it settles after a few seconds). A machine the game reports as without electricity reads "No power" in its header and blames no ingredient. Figures no longer overlap at any ingredient count
A machine card's output per minute now uses the machine's live speed, the same as the ingredient rows, so the two always agree at any speed
Drone rails show the crafters that feed them, one row per item, as three potentials in items per minute: max (the sources' output, capped at what the rail can carry at its drone speed and spacing), min (what is left if every machine taking the item off the line ahead runs full out) and now (what is left given the machines asking for it right now)
